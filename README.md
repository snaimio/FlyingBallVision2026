## 📌 Technical Overview
**FlyingBallVision** demonstrates cutting-edge spatial computing development for Apple Vision Pro (visionOS). It implements mixed-reality immersive space management, RealityKit 3D entity hierarchies, spatial audio, and interactive hand-tracking gesture controllers.

### 💼 Technical Highlights
- **ImmersiveSpace Management**: Transitions between 2D windowed UI and fully immersive 3D spatial environments.
- **RealityKit Entity Hierarchy**: Spawns and manages 3D physics entities using Apple's RealityKit content pipeline.
- **Spatial UI Controls**: Interactive `ToggleImmersiveSpaceButton` and spatial HUD built with visionOS-optimized SwiftUI glassmorphism.

## 🚀 Setup & Run
1. Clone the repository:
   ```bash
   git clone https://github.com/snaimio/FlyingBallVision2026.git
   cd FlyingBallVision2026
   open FlyingBallVision2026.xcodeproj
   ```
2. Select the **Apple Vision Pro Simulator** in Xcode and run (`⌘ + R`).
